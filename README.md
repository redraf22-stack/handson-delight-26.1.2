# Hands-On Delight — порт на Minecraft 26.1.2 (Fabric)

**Неофициальная сборка.** Порт мода [Hands-On Delight](https://github.com/Pocky-l/handson-delight) автора **Pocky**
с 1.21.1 на **Minecraft 26.1.2** (Fabric, Loom 1.17, Java 25, mojmap).

## Что делает

Кухня Farmer's Delight работает прямо в мире, без отдельного GUI: доска, печь, котёл, сковорода и бочка открываются
сценой — камера подъезжает к блоку, а еда, нож, ложка и жидкость рисуются в самом блоке:

- **доска** — резка по рецептам FD, слои, сборка блюд, книга рецептов;
- **котёл** — ингредиенты видны в воде, блюдо определяется по рецепту, полоска при помешивании, цвет бульона,
  звёзды за качество и добавочные порции;
- **печь** — гриль на 6 мест, переворот кусков по сторонам, книга того, что жарится;
- **сковорода** — масло, куски, пар и жар;
- **бочка** — напитки и брожение.

## Установка

В релизе лежат **оба файла сразу** — качаешь релиз, кладёшь оба в `mods`.

1. **Minecraft 26.1.2**, **Fabric Loader 0.19.5+**, **Java 25**.
2. В папку `mods` положить:
   - `handson_delight-1.4.1+26.1.2.jar`
   - `diegesis-1.0.0-beta.9+26.1.2.jar` (библиотека сцен, без неё мод не запустится) —
     [отдельный релиз Diegesis](https://github.com/redraf22-stack/diegesis-26.1.2/releases)
3. Отдельно нужны:
   - **Fabric API 0.155.2+26.1.2**
   - **Farmer's Delight Refabricated 26.1-3.6.30** — мод ничего своего не регистрирует, блоки и предметы остаются его.

## Аддоны Farmer's Delight

Ставятся как обычно, ничего настраивать не надо — их станции подхватываются сами, потому что мод читает рецепты
и иконки из игры, а не из списков:

- **End's Delight** — печь энда открывается как печь-гриль, в книге её 9 рецептов костра;
- **My Nether's Delight** — незеритовая печь также, режим синего пламени — только вид;
- их рецепты резки, сборки и варки видны в книгах доски и котла.

## Отличия от 1.21.1

- пар сковороды меньше оригинала (там он утраивался и читался как дым костра);
- сглаживание книги и табло отключено (`-Ddiegesis.smooth` включает обратно);
- дым печи и костра гасится, пока игрок работает за станцией рядом.

Журнал порта (все грабли 26.1, атласы, рецепты, рендер сцены) — в `PORT_NOTES.md`.

## Сборка

```bash
# нужен JDK 25 и Gradle; зависимости — в libs/
# libs/fdrf.jar          — Farmer's Delight Refabricated 26.1-3.6.30
# libs/diegesis.jar      — собранная библиотека Diegesis (см. её репозиторий)
gradle build --offline
```
